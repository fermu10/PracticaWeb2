# Mi Portafolio - PracticaWeb2

## Descripcion
Pagina web personal sencilla hecha para la actividad de autoaprendizaje de Programacion Web II (Univalle).
Tiene secciones de inicio, sobre mi, proyectos y un formulario de contacto de prueba.
El objetivo era practicar el trabajo con repositorios remotos, ramas, Pull Requests y despliegue con GitHub Pages.

## Tecnologias usadas
- HTML5
- CSS3
- JavaScript
- Git y GitHub
- GitHub Pages

## Sitio desplegado
https://fermu10.github.io/PracticaWeb2/

## Como ejecutarlo localmente
1. Clonar el repositorio:
   ```
   git clone https://github.com/fermu10/PracticaWeb2.git
   ```
2. Abrir el archivo `index.html` en el navegador.
